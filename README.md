# Sybaga — сайт-визитка ресторана

Одностраничный сайт семейного ресторана «Сыбаға» (Жезказган).
Двуязычный: **қазақша** (по умолчанию) и **русский**, переключение без перезагрузки.

Технология: чистые HTML + CSS + JavaScript. Без сборки, без npm, без бэкенда —
достаточно скопировать папку на любой хостинг, и сайт работает.

---

## Структура проекта

```
sybagazhez_site/
├── index.html                  ← разметка страницы (секции, SEO-теги, карта)
├── README.md                   ← этот файл
├── assets/
│   ├── css/
│   │   └── styles.css          ← все стили. Цвета — в самом верху, в блоке :root
│   ├── js/
│   │   ├── i18n.js             ← ВЕСЬ ТЕКСТ САЙТА (казахский + русский)
│   │   ├── content.js          ← МЕНЮ и ГАЛЕРЕЯ (блюда, цены, фото)
│   │   └── app.js              ← логика: язык, вкладки, лайтбокс, форма → WhatsApp
│   └── img/
│       ├── hero.jpg            ← главное фото
│       ├── about.jpg           ← фото в блоке «О нас»
│       ├── tea-ceremony.jpg    ← фото чайной церемонии
│       ├── hall-*.svg          ← ЗАГЛУШКИ залов (uly-dala, nomad, main)
│       ├── menu-*.jpg          ← фото к разделам меню (kazakh, steaks,
│       │                          author, feast, salads, bar)
│       ├── gallery-01…08.jpg   ← фото галереи
│       ├── og-image.png        ← готовое превью для WhatsApp/Telegram
│       └── favicon.svg         ← иконка вкладки браузера (сова)
└── .claude/launch.json         ← служебный файл для локального запуска, можно удалить
```

Заглушки остались только у трёх залов (`hall-*.svg`) — туда нужны ваши фото интерьера.

## Как открыть сайт локально

Самый простой способ — просто дважды кликнуть по `index.html`.
Сайт откроется в браузере и будет работать полностью.

Если хочется «как на настоящем сервере» (нужно только для проверки), в терминале:

```bash
python3 -m http.server 4321
```

Затем откройте в браузере `http://localhost:4321`.

## Как опубликовать сайт

### Вариант 1 — Netlify (проще всего, 2 минуты, бесплатно)

1. Зайдите на **app.netlify.com/drop**
2. Перетащите туда **всю папку** `sybagazhez_site` мышкой.
3. Сайт сразу получит адрес вида `random-name.netlify.app`.
4. В настройках сайта (*Site settings → Change site name*) можно поменять имя,
   а в *Domain management* — подключить свой домен, например `sybaga.kz`.

Чтобы обновить сайт позже — просто перетащите папку заново.

### Вариант 2 — GitHub Pages (бесплатно, нужен аккаунт GitHub)

1. Создайте репозиторий на github.com и загрузите в него файлы проекта.
2. *Settings → Pages → Source:* выберите ветку `main`, папку `/ (root)`, нажмите **Save**.
3. Через минуту сайт будет по адресу `https://ваш-логин.github.io/имя-репозитория/`.

### После публикации — обязательно

В `index.html` (строки ~17–30) замените адрес сайта
в двух местах: `<link rel="canonical">` и `<meta property="og:image">`.
Иначе при отправке ссылки в WhatsApp не подтянется картинка превью.

## Что нужно заполнить владельцу

### 1. Фотографии

**Фото блюд уже стоят на сайте.** Они взяты из вашего же QR-меню
**sybaga.kamiqr.com** — это реальная съёмка ресторана, 17 снимков,
обрезаны под нужные пропорции и сжаты (вся папка — около 4 МБ).

| Где на сайте | Файл | Что на снимке |
|---|---|---|
| Главный экран | `hero.jpg` | дастархан с самсой, чаем, құртом — съёмка на уровне стола |
| О нас | `about.jpg` | баурдак от шефа на тёмной ткани |
| Тәтті шәй | `tea-ceremony.jpg` | ұлттық тәттілер в деревянной тегене |
| Меню → Қазақ дастарханы | `menu-kazakh.jpg` | табанан с кониной на резном подносе |
| Меню → Стейки | `menu-steaks.jpg` | стейк «Рибай» из конины |
| Меню → Авторские | `menu-author.jpg` | фирменное блюдо от шефа |
| Меню → Большому столу | `menu-feast.jpg` | мясное ассорти |
| Меню → Салаты | `menu-salads.jpg` | фирменный салат с кониной |
| Меню → Бар и чай | `menu-bar.jpg` | бауырсак |
| Галерея | `gallery-01…08.jpg` | восемь блюд, подписи в `assets/js/content.js` |

**Чего пока не хватает — снимите и пришлите:**

| Где на сайте | Файл | Что снять | Размер |
|---|---|---|---|
| Залы | `hall-uly-dala.svg` | зал Uly Dala | 1200×800 |
| Залы | `hall-nomad.svg` | зал Nomad | 1200×800 |
| Залы | `hall-main.svg` | главный банкетный зал | 1200×800 |

Три зала — единственное место, где ещё стоят серые заглушки: фотографий
интерьера в QR-меню нет. Также стоит доснять **зал вечером, фасад
и гостей на тое** — их можно добавить в галерею (как — написано
в начале `assets/js/content.js`).

Чтобы заменить заглушку: положите фото в `assets/img/`, назовите
`hall-nomad.jpg`, и в `index.html` поправьте `hall-nomad.svg` → `hall-nomad.jpg`.
Фото лучше сжать перед загрузкой (например, на **squoosh.app**).

Старые заглушки `hero.svg`, `about.svg`, `menu-*.svg`, `gallery-*.svg`
больше нигде не используются — их можно удалить.

### 2. Меню и цены → `assets/js/content.js`

Блюда и цены **уже заполнены** — взяты с вашего QR-меню
**sybaga.kamiqr.com**. На сайте показаны 6 разделов по 8 позиций:
казахский стол, стейки, авторские блюда, большому столу, салаты и закуски,
бар и чай. Ниже блока меню стоит кнопка «Толық мәзірді ашу», которая ведёт
на полное меню в kamiqr — все 200+ позиций дублировать на сайте не нужно.

Важно: **цены не подтягиваются автоматически.** Когда меняете их в kamiqr,
поправьте и здесь — найдите блюдо и исправьте значение в `price`:

```js
{ name:{kk:'Қазақ ет', ru:'Казахское мясо'}, desc:{…}, price:'3 800 ₸' },
```

Там же можно добавлять и удалять блюда и целые разделы — в начале файла
подробная инструкция.

Отдельно вынесен **бизнес-ланч** (4 500 ₸, 12:00–15:00). Его текст меняется
в `assets/js/i18n.js` — ключи `lunchTag`, `lunchTxt`, `lunchUnit`,
а сама цифра «4 500 ₸» стоит в `index.html` в блоке `lunch__r`.

### 3. Вместимость залов → `assets/js/i18n.js`

Найдите строки `hall1Cap`, `hall2Cap`, `hall3Cap` (они есть в казахской и в русской части):

```
hall1Cap: '— орынға дейін',   →   hall1Cap: '30 орынға дейін',
hall1Cap: 'до — гостей',      →   hall1Cap: 'до 30 гостей',
```

### 4. Тексты

Весь текст сайта — в `assets/js/i18n.js`. Меняете фразу в кавычках, сохраняете,
обновляете страницу. Кавычки и названия слева от двоеточия трогать нельзя.

### 5. Если поменяется телефон

Номер встречается в трёх местах:
* `index.html` — ссылки `tel:` и `wa.me` (поиск по `77073404444`);
* `assets/js/app.js` — строка `var WHATSAPP = '77073404444';` в самом начале;
* `index.html` — блок структурированных данных `"telephone"`.

## Как работает бронирование

У сайта нет сервера, поэтому форма брони **не отправляет письма**.
Когда гость нажимает «Отправить в WhatsApp», сайт:

1. проверяет поля (имя, телефон, дата не в прошлом, число гостей 1–300);
2. собирает аккуратное сообщение с данными заявки;
3. открывает WhatsApp на номере `+7 707 340 4444` с уже готовым текстом.

Гостю остаётся нажать «Отправить». Заявка приходит вам в WhatsApp как обычное сообщение.
